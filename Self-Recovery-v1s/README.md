# Self Recovery v1 Firmware

Open the folder for the hardware/application you want, then download the UF2 or OTA ZIP inside it.

- Seeed-HOBO-Safe-v1
- RAK-HOBO-Safe-v1
- Heltec-Gateway-v1
- Seeed-Water-Distance-v1
- RAK-Water-Distance-v1
- Seeed-Water-Distance-HOBO-v1
- RAK-Water-Distance-HOBO-v1

For nRF52840 boards, UF2 is the normal USB drag-and-drop image and OTA ZIP is the BLE DFU image. Do not use factory-erase firmware for routine upgrades.
